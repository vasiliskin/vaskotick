# VaskoTick

Простая утилита учёта рабочего времени для Windows: проекты → задачи → таймер → отчёты.

![платформа](https://img.shields.io/badge/platform-Windows-blue) ![лицензия](https://img.shields.io/badge/license-MIT-green)

## Возможности

- Неограниченное число проектов: создание, переименование, удаление.
- Задачи внутри проектов: название, заметки, теги; редактирование и удаление.
- Таймер по выбранной задаче: старт / пауза / продолжить / стоп. Одновременно идёт один таймер.
- Защита таймера: состояние сохраняется автоматически; при закрытии приложения с идущим таймером время не теряется — после запуска отсчёт продолжается.
- Ручная корректировка времени задачи (± минуты), попадает в историю отдельной записью.
- История всех сессий с датами и длительностью.
- Отчёты за сегодня / неделю / месяц / всё время с разбивкой по проектам и задачам.
- Экспорт всех данных в текстовый файл.
- Иконка в системном трее: текущий таймер, быстрые «Пауза / Продолжить / Стоп»; закрытие окна сворачивает приложение в трей.
- Автозапуск с Windows (галочка в шапке окна).
- Защита от второго экземпляра.

## Скачать

Готовые сборки лежат в папке `release/`:

- `VaskoTick-1.2.0-Portable.exe` — portable-версия, установка не нужна.
- `VaskoTick-1.2.0-Setup.exe` — установщик с ярлыками и штатной деинсталляцией.

Данные хранятся в `%APPDATA%\VaskoTick\worktime-data.json`.

## Разработка

```bash
npm install     # один раз
npm start       # десктопное окно (Electron)
npm run dev     # предпросмотр рендерера в браузере (http://localhost:7100)
npm run dist    # собрать portable + установщик в release/
```

### Структура

```
src/
  main/       главный процесс Electron (окно, трей, IPC, хранилище)
  renderer/   интерфейс (vanilla JS, без сборщика)
scripts/
  dev-server.js  статический сервер предпросмотра
  start.js       запуск Electron (снимает ELECTRON_RUN_AS_NODE)
  build.js       сборка дистрибутивов через electron-builder API
assets/       иконки приложения и трея
release/      собранные дистрибутивы (не коммитятся)
```
